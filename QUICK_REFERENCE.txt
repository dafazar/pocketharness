❓ FAQ
═══════════════════════════════════════════════════════════════════════════════

Q: Model still returns 0 after Quick Fixes?
A: Do Standard Implementation (add file validation in C++ and Kotlin)

Q: Model loads but no tokens are generated?
A: registerPlugin() wasn't registered. Check Kotlin logcat for:
   "✅ registerPlugin() called successfully"

Q: Getting SIGBUS crash?
A: use_mmap is still true. Change it to false in llama_jni.cpp

Q: "File not found" error?
A: Model path is wrong. Check with: adb shell ls /actual/path/

Q: "Insufficient memory" error?
A: Close other apps or use smaller model (3B-7B instead of 13B)

Q: How to test the fix worked?
A: Check logcat shows "✅ nativeLoadModel: SUCCESS" and model loads in UI
